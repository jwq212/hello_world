# InkCinema Project Schema

Version: 1.0.0

RFC: 0002

Status: Stable

---

# Purpose

This document defines the only valid project object used by InkCinema.

Every Agent must consume and produce this object.

No Agent may introduce incompatible fields.

---

# Philosophy

There is only one Project.

Agents never exchange prompts.

Agents never exchange markdown.

Agents exchange Project.

Project is the source of truth.

Everything else is generated from Project.
